# Xonix Web App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a faithful, polished web reproduction of Xonix (1984) — playable on desktop and mobile, installable as a PWA, auto-deployed to GitHub Pages.

**Architecture:** Pure, fully-tested game core (`src/core/*`, no DOM imports) driven by a fixed-timestep 60 Hz loop; a read-only canvas renderer; thin input/audio/UI/persist layers around it. State machine in `core/game.ts` emits events that audio/renderer/screens consume.

**Tech Stack:** TypeScript (strict), Vite, vitest, vite-plugin-pwa, plain Canvas 2D + DOM overlays, WebAudio. Node ≥22 / npm ≥10 (verified on this machine: node v22.22.3, npm 10.9.8).

**Spec:** `docs/superpowers/specs/2026-11-23-xonix-design.md` — the plan argues from the spec; executors read both.

## Global Constraints

- TypeScript `strict`; **no runtime dependencies** — dev deps only: `vite`, `vitest`, `typescript`, `vite-plugin-pwa` (PWA dep added in Task 15, not before).
- **`src/core/**` must never import DOM, canvas, or other browser APIs.** Tests for core run in plain Node.
- Cell size = 4 px. Presets: **classic** 320×200 canvas, HUD 16 px, grid 80×46, border 2 cells; **roomy** 640×400 canvas, HUD 32 px, grid 160×92, border 2 cells (exact dims fixed here per spec §5).
- Palette: water `#000000`, land/border `#00FFFF`, trail `#FF00FF`, player & balls `#FFFFFF`, warders `#FF00FF`.
- Fixed timestep 60 Hz (16.6667 ms per logic tick).
- Rules constants (pre-calibration defaults, spec §3): fill target `0.75 + 0.01*(level-1)` capped `0.85`; lives `3`; score = `cells × level`; level-clear bonus = `lives × 100 × level`.
- `localStorage` keys: `xonix.settings`, `xonix.scores`; every read/write wrapped in try/catch with in-memory fallback.
- Non-goals (spec §1): no gamepad, no music, no backend leaderboard, no e2e test suite.
- Every task ends with a green `npm test` (where tests exist) and a git commit using conventional-commit messages.
- Repo identity already configured locally (JEOLeary). No remote exists until Task 16.

```ts
export type Cell = 0 | 1 | 2;
export const WATER = 0 as const;
export const LAND = 1 as const;
export const TRAIL = 2 as const;

export interface Grid {
  w: number;
  h: number;
  cells: Uint8Array; // index = y * w + x
}

export function createGrid(w: number, h: number, border: number): Grid {
  const cells = new Uint8Array(w * h); // all WATER
  for (let y = 0; y < h; y++) {
    for (let x = 0; x < w; x++) {
      if (x < border || y < border || x >= w - border || y >= h - border) {
        cells[y * w + x] = LAND;
      }
    }
  }
  return { w, h, cells };
}

export function getCell(g: Grid, x: number, y: number): Cell {
  if (x < 0 || y < 0 || x >= g.w || y >= g.h) return LAND;
  return g.cells[y * g.w + x] as Cell;
}

export function setCell(g: Grid, x: number, y: number, c: Cell): void {
  if (x < 0 || y < 0 || x >= g.w || y >= g.h) return;
  g.cells[y * g.w + x] = c;
}

export function countCells(g: Grid, c: Cell): number {
  let n = 0;
  for (let i = 0; i < g.cells.length; i++) if (g.cells[i] === c) n++;
  return n;
}

export function landFraction(g: Grid): number {
  return countCells(g, LAND) / g.cells.length;
}
```

`src/core/fill.ts`:
```ts
import { Grid, getCell, WATER, LAND, TRAIL } from './grid';

export interface EnemyPos {
  x: number;
  y: number;
}

export function regionAt(g: Grid, sx: number, sy: number, visited: Uint8Array): number[] {
  const region: number[] = [];
  if (getCell(g, sx, sy) !== WATER) return region;
  const seed = sy * g.w + sx;
  visited[seed] = 1;
  const stack: number[] = [seed];
  while (stack.length > 0) {
    const i = stack.pop()!;
    region.push(i);
    const x = i % g.w;
    const y = Math.floor(i / g.w);
    const neighbors = [i - 1, i + 1, i - g.w, i + g.w];
    const coords = [[x - 1, y], [x + 1, y], [x, y - 1], [x, y + 1]];
    for (let n = 0; n < 4; n++) {
      const [nx, ny] = coords[n];
      if (nx < 0 || ny < 0 || nx >= g.w || ny >= g.h) continue;
      const ni = neighbors[n];
      if (visited[ni] || g.cells[ni] !== WATER) continue;
      visited[ni] = 1;
      stack.push(ni);
    }
  }
  return region;
}

export function sealAndClaim(g: Grid, enemies: EnemyPos[]): { claimedCells: number[] } {
  const claimedCells: number[] = [];
  // 1. the trail itself becomes land
  for (let i = 0; i < g.cells.length; i++) {
    if (g.cells[i] === TRAIL) {
      g.cells[i] = LAND;
      claimedCells.push(i);
    }
  }
  // 2. claim every enemy-free water region
  const enemyCells = new Set(
    enemies.map((e) => Math.floor(e.y) * g.w + Math.floor(e.x)),
  );
  const visited = new Uint8Array(g.cells.length);
  for (let i = 0; i < g.cells.length; i++) {
    if (g.cells[i] !== WATER || visited[i]) continue;
    const region = regionAt(g, i % g.w, Math.floor(i / g.w), visited);
    let hasEnemy = false;
    for (const rc of region) {
      if (enemyCells.has(rc)) {
        hasEnemy = true;
        break;
      }
    }
    if (!hasEnemy) {
      for (const rc of region) {
        g.cells[rc] = LAND;
        claimedCells.push(rc);
      }
    }
  }
  return { claimedCells };
}

export function clearTrail(g: Grid): void {
  for (let i = 0; i < g.cells.length; i++) {
    if (g.cells[i] === TRAIL) g.cells[i] = WATER;
  }
}
```

**Files:**

**Interfaces:**
- Consumes: `Grid`, `getCell`, `setCell`, `LAND`, `WATER`, `TRAIL` from `grid.ts`.
- Produces (used by `game.ts` Task 9 and `input.ts` Task 11):
  - `type Dir = 'up' | 'down' | 'left' | 'right'`
  - `interface Player { x: number; y: number; dir: Dir | null; pending: Dir | null; drawing: boolean }`
  - `createPlayer(g: Grid, border: number): Player` — spawns at center of cell (border−1, border−1)
  - `setDirection(p: Player, d: Dir): void` — queues `pending`
  - `tickPlayer(g: Grid, p: Player, speed: number): PlayerTickResult` — advances one 60 Hz step; `speed` in cells/tick
  - `interface PlayerTickResult { moved: boolean; started: boolean; sealed: boolean; enteredCell: { x: number; y: number } | null }`

**Rules encoded here (spec §2):** glide continues in `dir`; `pending` overrides next tick; moving land→water starts the trail and marks each newly entered cell TRAIL; water→land while drawing = seal (position snaps to the land cell center, `sealed: true`); a target cell that is TRAIL **and not the player's current cell** is rejected (cannot cross own trail); out-of-bounds targets are rejected.

```ts
import { Grid, getCell, setCell, LAND, WATER, TRAIL } from './grid';

export type Dir = 'up' | 'down' | 'left' | 'right';

export interface Player {
  x: number;
  y: number;
  dir: Dir | null;
  pending: Dir | null;
  drawing: boolean;
}

export interface PlayerTickResult {
  moved: boolean;
  started: boolean;
  sealed: boolean;
  enteredCell: { x: number; y: number } | null;
}

const DELTA: Record<Dir, { dx: number; dy: number }> = {
  up: { dx: 0, dy: -1 },
  down: { dx: 0, dy: 1 },
  left: { dx: -1, dy: 0 },
  right: { dx: 1, dy: 0 },
};

export function createPlayer(g: Grid, border: number): Player {
  return {
    x: border - 1 + 0.5,
    y: border - 1 + 0.5,
    dir: null,
    pending: null,
    drawing: false,
  };
}

export function setDirection(p: Player, d: Dir): void {
  p.pending = d;
}

export function tickPlayer(g: Grid, p: Player, speed: number): PlayerTickResult {
  const res: PlayerTickResult = { moved: false, started: false, sealed: false, enteredCell: null };
  if (p.pending) {
    p.dir = p.pending;
    p.pending = null;
  }
  if (!p.dir) return res;

  const { dx, dy } = DELTA[p.dir];
  const nx = p.x + dx * speed;
  const ny = p.y + dy * speed;
  const tx = Math.floor(nx);
  const ty = Math.floor(ny);
  if (tx < 0 || ty < 0 || tx >= g.w || ty >= g.h) return res; // press against the wall

  const curX = Math.floor(p.x);
  const curY = Math.floor(p.y);
  const isCurrent = tx === curX && ty === curY;
  const cell = getCell(g, tx, ty);

  // cannot cross your own trail (standing on it is fine)
  if (cell === TRAIL && !isCurrent) return res;

  if (cell === LAND && !isCurrent) {
    if (p.drawing) {
      // reconnect → seal
      p.drawing = false;
      p.x = tx + 0.5;
      p.y = ty + 0.5;
      res.moved = true;
      res.sealed = true;
      return res;
    }
    p.x = nx;
    p.y = ny;
    res.moved = true;
    return res;
  }

  // water (or staying on the current trail cell): move freely
  const oldX = Math.floor(p.x);
  const oldY = Math.floor(p.y);
  p.x = nx;
  p.y = ny;
  res.moved = true;

  const cx = Math.floor(p.x);
  const cy = Math.floor(p.y);
  if (cell === WATER && !isCurrent && !p.drawing) {
    p.drawing = true;
    res.started = true;
  }
  if ((cx !== oldX || cy !== oldY) && getCell(g, cx, cy) === WATER) {
    setCell(g, cx, cy, TRAIL);
    res.enteredCell = { x: cx, y: cy };
  }
  return res;
}
```

```ts
import { Grid, getCell, WATER } from './grid';

export interface Ball {
  x: number;
  y: number;
  dx: 1 | -1;
  dy: 1 | -1;
}

export interface Warder {
  p: number;
  dir: 1 | -1;
}

export interface RingCell {
  x: number;
  y: number;
}

export function buildRing(g: Grid, border: number): RingCell[] {
  const k = border - 1;
  const ring: RingCell[] = [];
  for (let x = k; x <= g.w - 1 - k; x++) ring.push({ x, y: k });                 // top L→R
  for (let y = k + 1; y <= g.h - 1 - k; y++) ring.push({ x: g.w - 1 - k, y });   // right T→B
  for (let x = g.w - 2 - k; x >= k; x--) ring.push({ x, y: g.h - 1 - k });       // bottom R→L
  for (let y = g.h - 2 - k; y >= k + 1; y--) ring.push({ x: k, y });             // left B→T
  return ring;
}

export function createBalls(g: Grid, count: number, rng: () => number): Ball[] {
  const balls: Ball[] = [];
  let guard = 0;
  while (balls.length < count && guard++ < 10000) {
    const x = Math.floor(rng() * g.w);
    const y = Math.floor(rng() * g.h);
    if (getCell(g, x, y) !== WATER) continue;
    balls.push({
      x: x + 0.5,
      y: y + 0.5,
      dx: rng() < 0.5 ? -1 : 1,
      dy: rng() < 0.5 ? -1 : 1,
    });
  }
  return balls;
}

export function tickBalls(g: Grid, balls: Ball[], speed: number): void {
  for (const b of balls) {
    const nx = b.x + b.dx * speed;
    if (getCell(g, Math.floor(nx), Math.floor(b.y)) === WATER) {
      b.x = nx;
    } else {
      b.dx = b.dx === 1 ? -1 : 1;
    }
    const ny = b.y + b.dy * speed;
    if (getCell(g, Math.floor(b.x), Math.floor(ny)) === WATER) {
      b.y = ny;
    } else {
      b.dy = b.dy === 1 ? -1 : 1;
    }
  }
}

export function createWarders(ring: RingCell[], count: number): Warder[] {
  const warders: Warder[] = [];
  for (let i = 0; i < count; i++) {
    // half-step offset so no warder starts on the player's spawn cell ring[0]
    warders.push({
      p: ((i + 0.5) * ring.length) / count,
      dir: i % 2 === 0 ? 1 : -1,
    });
  }
  return warders;
}

export function tickWarders(warders: Warder[], ring: RingCell[], speed: number): void {
  const last = ring.length - 1;
  for (const w of warders) {
    w.p += w.dir * speed;
    if (w.p > last) {
      w.p = 2 * last - w.p;
      w.dir = -1;
    } else if (w.p < 0) {
      w.p = -w.p;
      w.dir = 1;
    }
  }
}

export function warderPos(w: Warder, ring: RingCell[]): RingCell {
  const i = Math.max(0, Math.min(ring.length - 1, Math.round(w.p)));
  return ring[i];
}
```

```ts
import { Grid, getCell, TRAIL } from './grid';
import type { Player } from './player';
import type { Ball, Warder, RingCell } from './enemies';
import { warderPos } from './enemies';

export type DeathCause = 'ball' | 'trail' | 'warder';

function touchesTrail(g: Grid, x: number, y: number): boolean {
  if (getCell(g, x, y) === TRAIL) return true;
  return (
    getCell(g, x + 1, y) === TRAIL ||
    getCell(g, x - 1, y) === TRAIL ||
    getCell(g, x, y + 1) === TRAIL ||
    getCell(g, x, y - 1) === TRAIL
  );
}

export function checkDeath(
  g: Grid,
  player: Player,
  balls: Ball[],
  warders: Warder[],
  ring: RingCell[],
): DeathCause | null {
  const px = Math.floor(player.x);
  const py = Math.floor(player.y);

  for (const b of balls) {
    if (Math.floor(b.x) === px && Math.floor(b.y) === py) return 'ball';
  }
  for (const b of balls) {
    if (touchesTrail(g, Math.floor(b.x), Math.floor(b.y))) return 'trail';
  }
  for (const w of warders) {
    const pos = warderPos(w, ring);
    if (pos.x === px && pos.y === py) return 'warder';
  }
  return null;
}
```

```ts
export type PresetName = 'classic' | 'roomy';

export interface Preset {
  name: PresetName;
  canvasW: number;
  canvasH: number;
  hudH: number;
  cellPx: number;
  border: number;
  cols: number;
  rows: number;
}

export const PRESETS: Record<PresetName, Preset> = {
  classic: { name: 'classic', canvasW: 320, canvasH: 200, hudH: 16, cellPx: 4, border: 2, cols: 80, rows: 46 },
  roomy:   { name: 'roomy',   canvasW: 640, canvasH: 400, hudH: 32, cellPx: 4, border: 2, cols: 160, rows: 92 },
};

export interface Tuning {
  balls: number;
  ballSpeed: number;
  warders: number;
  warderSpeed: number;
  playerSpeed: number;
  fillTarget: number;
}

const CLASSIC_COLS = PRESETS.classic.cols;
const CLASSIC_AREA = PRESETS.classic.cols * PRESETS.classic.rows;

export function tuningFor(level: number, preset: Preset): Tuning {
  const areaRatio = (preset.cols * preset.rows) / CLASSIC_AREA;
  const linearRatio = preset.cols / CLASSIC_COLS;
  const baseBalls = Math.min(1 + level, 10);
  return {
    balls: Math.max(1, Math.round(baseBalls * areaRatio)),
    ballSpeed: Math.min(0.10 + 0.012 * (level - 1), 0.26),
    warders: Math.min(4 + Math.floor(level / 4), 8),
    warderSpeed: 0.12,
    playerSpeed: 0.20 * linearRatio,
    fillTarget: Math.min(0.75 + 0.01 * (level - 1), 0.85),
  };
}
```

```ts
export interface ScoreEntry {
  initials: string;
  score: number;
  level: number;
  date: string;
}

export function scoreForClaim(cells: number, level: number): number {
  return cells * level;
}

export function levelClearBonus(lives: number, level: number): number {
  return lives * 100 * level;
}

export function qualifiesForTopTen(list: ScoreEntry[], score: number): boolean {
  return list.length < 10 || score > list[list.length - 1].score;
}

export function insertScore(list: ScoreEntry[], entry: ScoreEntry): ScoreEntry[] {
  return [...list, entry]
    .sort((a, b) => b.score - a.score || a.date.localeCompare(b.date))
    .slice(0, 10);
}
```

```ts
import { createGrid, landFraction, type Grid } from './grid';
import { clearTrail, sealAndClaim } from './fill';
import {
  createPlayer, setDirection as queueDirection, tickPlayer,
  type Player, type Dir,
} from './player';
import {
  buildRing, createBalls, tickBalls, createWarders, tickWarders,
  type Ball, type Warder, type RingCell,
} from './enemies';
import { checkDeath, type DeathCause } from './collision';
import { tuningFor, type Preset } from './levels';
import { scoreForClaim, levelClearBonus } from './scoring';

export type GameState = 'title' | 'playing' | 'paused' | 'dying' | 'levelclear' | 'gameover';

export type GameEvent =
  | { type: 'start' }
  | { type: 'claim'; cells: number[]; score: number }
  | { type: 'death'; cause: DeathCause; lives: number }
  | { type: 'levelclear'; level: number; bonus: number }
  | { type: 'gameover'; score: number }
  | { type: 'pause' }
  | { type: 'resume' };

export interface Game {
  state: GameState;
  preset: Preset;
  grid: Grid;
  player: Player;
  balls: Ball[];
  warders: Warder[];
  ring: RingCell[];
  level: number;
  lives: number;
  score: number;
  pct: number;
  stateTimer: number;
  graceTicks: number;
  events: GameEvent[];
}

const DIE_FREEZE = 60;   // ticks of death animation before respawn/gameover
const CLEAR_HOLD = 120;  // ticks of level-clear tally before the next level
const SPAWN_GRACE = 60;  // ticks of post-respawn invulnerability

function random(): number {
  return Math.random();
}

export function createGame(preset: Preset): Game {
  const grid = createGrid(preset.cols, preset.rows, preset.border);
  return {
    state: 'title',
    preset,
    grid,
    player: createPlayer(grid, preset.border),
    balls: [],
    warders: [],
    ring: buildRing(grid, preset.border),
    level: 1,
    lives: 3,
    score: 0,
    pct: landFraction(grid),
    stateTimer: 0,
    graceTicks: 0,
    events: [],
  };
}

export function startLevel(g: Game): void {
  const t = tuningFor(g.level, g.preset);
  g.grid = createGrid(g.preset.cols, g.preset.rows, g.preset.border);
  g.ring = buildRing(g.grid, g.preset.border);
  g.player = createPlayer(g.grid, g.preset.border);
  g.balls = createBalls(g.grid, t.balls, random);
  g.warders = createWarders(g.ring, t.warders);
  g.pct = landFraction(g.grid);
  g.graceTicks = 0;
}

export function startGame(g: Game): void {
  g.level = 1;
  g.lives = 3;
  g.score = 0;
  startLevel(g);
  g.state = 'playing';
  g.events.push({ type: 'start' });
}

export function returnToTitle(g: Game): void {
  g.state = 'title';
}

export function setDirection(g: Game, d: Dir): void {
  if (g.state === 'playing') queueDirection(g.player, d);
}

export function togglePause(g: Game): void {
  if (g.state === 'playing') {
    g.state = 'paused';
    g.events.push({ type: 'pause' });
  } else if (g.state === 'paused') {
    g.state = 'playing';
    g.events.push({ type: 'resume' });
  }
}

export function drainEvents(g: Game): GameEvent[] {
  const out = g.events;
  g.events = [];
  return out;
}

function respawn(g: Game): void {
  g.player = createPlayer(g.grid, g.preset.border);
  g.graceTicks = SPAWN_GRACE;
}

export function tick(g: Game): void {
  switch (g.state) {
    case 'dying':
      if (--g.stateTimer <= 0) {
        if (g.lives <= 0) {
          g.state = 'gameover';
          g.events.push({ type: 'gameover', score: g.score });
        } else {
          respawn(g);
          g.state = 'playing';
        }
      }
      return;
    case 'levelclear':
      if (--g.stateTimer <= 0) {
        g.level++;
        startLevel(g);
        g.state = 'playing';
      }
      return;
    case 'title':
    case 'paused':
    case 'gameover':
      return;
    case 'playing':
      break;
  }

  const t = tuningFor(g.level, g.preset);

  // 1. player
  const pr = tickPlayer(g.grid, g.player, t.playerSpeed);
  if (pr.sealed) {
    const { claimedCells } = sealAndClaim(g.grid, g.balls);
    if (claimedCells.length > 0) {
      g.score += scoreForClaim(claimedCells.length, g.level);
      g.events.push({ type: 'claim', cells: claimedCells, score: g.score });
    }
  }

  // 2. enemies
  tickBalls(g.grid, g.balls, t.ballSpeed);
  tickWarders(g.warders, g.ring, t.warderSpeed);

  // 3. death?
  const cause = g.graceTicks > 0 ? null : checkDeath(g.grid, g.player, g.balls, g.warders, g.ring);
  if (g.graceTicks > 0) g.graceTicks--;
  if (cause) {
    g.lives--;
    clearTrail(g.grid);
    g.events.push({ type: 'death', cause, lives: g.lives });
    g.state = 'dying';
    g.stateTimer = DIE_FREEZE;
    return;
  }

  // 4. fill target reached?
  g.pct = landFraction(g.grid);
  if (g.pct >= t.fillTarget) {
    const bonus = levelClearBonus(g.lives, g.level);
    g.score += bonus;
    g.state = 'levelclear';
    g.stateTimer = CLEAR_HOLD;
    g.events.push({ type: 'levelclear', level: g.level, bonus });
  }
}
```

```ts
import type { Game, GameEvent } from '../core/game';
import type { Preset } from '../core/levels';
import { LAND, TRAIL } from '../core/grid';
import { warderPos } from '../core/enemies';

const COLORS = {
  water: '#000000',
  land: '#00FFFF',
  trail: '#FF00FF',
  player: '#FFFFFF',
  ball: '#FFFFFF',
  warder: '#FF00FF',
  hud: '#FFFFFF',
  flash: '#FFFFFF',
};

export class Renderer {
  private ctx: CanvasRenderingContext2D;
  private flash = new Map<number, number>(); // flat cell index → frames remaining

  constructor(canvas: HTMLCanvasElement, private preset: Preset) {
    const ctx = canvas.getContext('2d');
    if (!ctx) throw new Error('2d canvas context unavailable');
    this.ctx = ctx;
    canvas.width = preset.canvasW;
    canvas.height = preset.canvasH;
    ctx.imageSmoothingEnabled = false;
  }

  onEvent(e: GameEvent): void {
    if (e.type === 'claim') {
      for (const i of e.cells) this.flash.set(i, 6);
    }
  }

  draw(g: Game): void {
    const { ctx, preset } = this;
    const { cellPx, hudH, cols, rows, canvasW, canvasH } = preset;
    const oy = hudH; // playfield origin (below HUD strip)

    // 1. water background
    ctx.fillStyle = COLORS.water;
    ctx.fillRect(0, oy, canvasW, canvasH - hudH);

    // 2. land + trail, run-length merged per row
    for (let y = 0; y < rows; y++) {
      let runColor = -1;
      let runStart = 0;
      for (let x = 0; x <= cols; x++) {
        const c = x < cols ? g.grid.cells[y * cols + x] : -1;
        if (c !== runColor) {
          if (runColor === LAND || runColor === TRAIL) {
            ctx.fillStyle = runColor === LAND ? COLORS.land : COLORS.trail;
            ctx.fillRect(runStart * cellPx, oy + y * cellPx, (x - runStart) * cellPx, cellPx);
          }
          runColor = c;
          runStart = x;
        }
      }
    }

    // 3. capture flash (freshly claimed cells blink white)
    if (this.flash.size > 0) {
      ctx.fillStyle = COLORS.flash;
      for (const [i, t] of this.flash) {
        const x = i % cols;
        const y = Math.floor(i / cols);
        ctx.fillRect(x * cellPx, oy + y * cellPx, cellPx, cellPx);
        if (t <= 1) this.flash.delete(i);
        else this.flash.set(i, t - 1);
      }
    }

    // 4. player (or death explosion while dying)
    const pxc = Math.floor(g.player.x);
    const pyc = Math.floor(g.player.y);
    if (g.state === 'dying') {
      const phase = Math.floor(g.stateTimer / 4) % 2;
      ctx.fillStyle = phase === 0 ? COLORS.player : COLORS.trail;
      for (const [dx, dy] of [[0, 0], [1, 0], [-1, 0], [0, 1], [0, -1]]) {
        ctx.fillRect((pxc + dx) * cellPx, oy + (pyc + dy) * cellPx, cellPx, cellPx);
      }
    } else {
      ctx.fillStyle = COLORS.player;
      ctx.fillRect(pxc * cellPx, oy + pyc * cellPx, cellPx, cellPx);
    }

    // 5. balls
    ctx.fillStyle = COLORS.ball;
    for (const b of g.balls) {
      ctx.fillRect(Math.floor(b.x) * cellPx, oy + Math.floor(b.y) * cellPx, cellPx, cellPx);
    }

    // 6. warders (magenta, distinct against cyan border)
    ctx.fillStyle = COLORS.warder;
    for (const w of g.warders) {
      const c = warderPos(w, g.ring);
      ctx.fillRect(c.x * cellPx, oy + c.y * cellPx, cellPx, cellPx);
    }

    // 7. HUD strip
    ctx.fillStyle = COLORS.water;
    ctx.fillRect(0, 0, canvasW, hudH);
    ctx.fillStyle = COLORS.hud;
    ctx.font = `bold ${hudH - 8}px monospace`;
    ctx.textBaseline = 'middle';
    ctx.textAlign = 'left';
    const pct = Math.floor(g.pct * 100);
    const hud = `SCORE ${String(g.score).padStart(6, '0')}  LIVES ${g.lives}  FILL ${pct}%  LV ${g.level}`;
    ctx.fillText(hud, 4, hudH / 2);
  }
}
```

```ts
function frame(now: number): void {
  acc += Math.min(now - last, 250);
```

  - Touch: swipe ≥24px → `onDir` (dominant axis); quick tap (<24px, <300ms) → `onStart`

```ts
import type { Dir } from '../core/player';

export interface InputHandlers {
  onDir: (d: Dir) => void;
  onStart: () => void;
  onPause: () => void;
}

const KEY_DIRS: Record<string, Dir> = {
  ArrowUp: 'up', ArrowDown: 'down', ArrowLeft: 'left', ArrowRight: 'right',
  w: 'up', a: 'left', s: 'down', d: 'right',
  W: 'up', A: 'left', S: 'down', D: 'right',
};

export function attachInput(h: InputHandlers): () => void {
  const onKeyDown = (ev: KeyboardEvent): void => {
    if (ev.key in KEY_DIRS) {
      h.onDir(KEY_DIRS[ev.key]);
      ev.preventDefault();
    } else if (ev.key === 'Enter' || ev.key === ' ') {
      h.onStart();
      ev.preventDefault();
    } else if (ev.key === 'p' || ev.key === 'P' || ev.key === 'Escape') {
      h.onPause();
      ev.preventDefault();
    }
  };

  // swipe-to-steer + tap-to-start
  let sx = 0, sy = 0, st = 0, tracking = false;
  const onTouchStart = (ev: TouchEvent): void => {
    // R13: controls own their taps — never let a control tap also fire tap-to-start
    if ((ev.target as HTMLElement | null)?.closest('button, .screen')) return;
    const t = ev.changedTouches[0];
    sx = t.clientX; sy = t.clientY; st = Date.now(); tracking = true;
  };
  const onTouchEnd = (ev: TouchEvent): void => {
    if ((ev.target as HTMLElement | null)?.closest('button, .screen')) return; // R13
    if (!tracking) return;
    tracking = false;
    const t = ev.changedTouches[0];
    const dx = t.clientX - sx;
    const dy = t.clientY - sy;
    if (Math.hypot(dx, dy) < 24) {
      if (Date.now() - st < 300) h.onStart();
      return;
    }
    h.onDir(Math.abs(dx) > Math.abs(dy) ? (dx > 0 ? 'right' : 'left') : (dy > 0 ? 'down' : 'up'));
  };

  // on-screen D-pad + pause button
  const dpadButtons = Array.from(document.querySelectorAll<HTMLButtonElement>('[data-dir]'));
  const onDpad = (ev: Event): void => {
    const btn = ev.currentTarget as HTMLButtonElement;
    h.onDir(btn.dataset.dir as Dir);
  };
  const stopTouch = (ev: Event): void => ev.preventDefault();
  for (const b of dpadButtons) {
    b.addEventListener('pointerdown', onDpad);
    b.addEventListener('touchstart', stopTouch, { passive: false });
  }
  const pauseBtn = document.querySelector('#btn-pause');
  const onPauseClick = (): void => h.onPause();
  pauseBtn?.addEventListener('click', onPauseClick);

  window.addEventListener('keydown', onKeyDown);
  window.addEventListener('touchstart', onTouchStart, { passive: true });
  window.addEventListener('touchend', onTouchEnd, { passive: true });

  return () => {
    window.removeEventListener('keydown', onKeyDown);
    window.removeEventListener('touchstart', onTouchStart);
    window.removeEventListener('touchend', onTouchEnd);
    for (const b of dpadButtons) {
      b.removeEventListener('pointerdown', onDpad);
      b.removeEventListener('touchstart', stopTouch);
    }
    pauseBtn?.removeEventListener('click', onPauseClick);
  };
}
```

- [ ] **Step 1: Write audio.ts**

```ts
import type { GameEvent } from '../core/game';

export class GameAudio {
  private ctx: AudioContext | null = null;
  private enabled = true;

  unlock(): void {
    if (!this.ctx) {
      const w = window as unknown as { AudioContext?: typeof AudioContext; webkitAudioContext?: typeof AudioContext };
      const AC = w.AudioContext ?? w.webkitAudioContext;
      if (!AC) return;
      this.ctx = new AC();
    }
    if (this.ctx.state === 'suspended') void this.ctx.resume();
  }

  setEnabled(b: boolean): void {
    this.enabled = b;
  }

  private tone(freq: number, dur: number, delay = 0, vol = 0.07): void {
    if (!this.enabled || !this.ctx) return;
    const t0 = this.ctx.currentTime + delay;
    const osc = this.ctx.createOscillator();
    const gain = this.ctx.createGain();
    osc.type = 'square';
    osc.frequency.setValueAtTime(freq, t0);
    gain.gain.setValueAtTime(vol, t0);
    gain.gain.exponentialRampToValueAtTime(0.0001, t0 + dur);
    osc.connect(gain);
    gain.connect(this.ctx.destination);
    osc.start(t0);
    osc.stop(t0 + dur + 0.02);
  }

  handle(e: GameEvent): void {
    switch (e.type) {
      case 'claim':
        this.tone(300 + Math.min(e.cells.length, 400), 0.06);
        break;
      case 'death':
        this.tone(400, 0.10);
        this.tone(200, 0.15, 0.10);
        this.tone(100, 0.25, 0.25);
        break;
      case 'levelclear':
        [523, 659, 784, 1047].forEach((f, i) => this.tone(f, 0.12, i * 0.10));
        break;
      case 'gameover':
        [392, 330, 262, 196].forEach((f, i) => this.tone(f, 0.18, i * 0.15));
        break;
      case 'start':
      case 'pause':
      case 'resume':
        this.tone(660, 0.05);
        break;
    }
  }
}
```

```ts
import type { ScoreEntry } from '../core/scoring';

export interface Settings {
  displaySize: 'fit' | '1x' | '2x' | '3x' | 'fullscreen';
  playfield: 'classic' | 'roomy';
  sound: boolean;
}

export const DEFAULT_SETTINGS: Settings = {
  displaySize: 'fit',
  playfield: 'classic',
  sound: true,
};

let storageBroken = false;
let memSettings: Settings = { ...DEFAULT_SETTINGS };
let memScores: ScoreEntry[] = [];

export function loadSettings(): Settings {
  if (storageBroken) return { ...memSettings };
  try {
    const raw = localStorage.getItem('xonix.settings');
    if (raw) {
      memSettings = { ...DEFAULT_SETTINGS, ...(JSON.parse(raw) as Partial<Settings>) };
      return { ...memSettings };
    }
  } catch {
    storageBroken = true;
  }
  return { ...memSettings };
}

export function saveSettings(s: Settings): void {
  memSettings = { ...s };
  if (storageBroken) return;
  try {
    localStorage.setItem('xonix.settings', JSON.stringify(s));
  } catch {
    storageBroken = true;
  }
}

export function loadScores(): ScoreEntry[] {
  if (storageBroken) return [...memScores];
  try {
    const raw = localStorage.getItem('xonix.scores');
    if (raw) {
      const parsed: unknown = JSON.parse(raw);
      if (Array.isArray(parsed)) {
        memScores = parsed.filter(
          (e): e is ScoreEntry =>
            typeof e === 'object' && e !== null &&
            typeof (e as ScoreEntry).score === 'number' &&
            typeof (e as ScoreEntry).initials === 'string',
        );
        return [...memScores];
      }
    }
  } catch {
    storageBroken = true;
  }
  return [...memScores];
}

export function saveScores(list: ScoreEntry[]): void {
  memScores = [...list];
  if (storageBroken) return;
  try {
    localStorage.setItem('xonix.scores', JSON.stringify(list));
  } catch {
    storageBroken = true;
  }
}
```

```ts
import type { Game } from '../core/game';
import { qualifiesForTopTen, insertScore, type ScoreEntry } from '../core/scoring';
import {
  loadScores, saveScores, loadSettings, saveSettings, type Settings,
} from '../persist/storage';

export interface ScreensCallbacks {
  onStart: () => void;
  onResume: () => void;
  onQuitToTitle: () => void;
  onSettingsApplied: (s: Settings) => void;
}

export interface Screens {
  sync(g: Game): void;
}

export function initScreens(cb: ScreensCallbacks): Screens {
  const el = <T extends HTMLElement>(id: string): T => {
    const node = document.getElementById(id);
    if (!node) throw new Error(`missing #${id}`);
    return node as T;
  };

  const overlays = {
    title: el('screen-title'),
    settings: el('screen-settings'),
    pause: el('screen-pause'),
    levelclear: el('screen-levelclear'),
    gameover: el('screen-gameover'),
  };

  let scores = loadScores();
  let settings = loadSettings();
  let pendingEntry: ScoreEntry | null = null;

  function showOnly(name: keyof typeof overlays | null): void {
    for (const o of Object.values(overlays)) o.classList.add('hidden');
    if (name) overlays[name].classList.remove('hidden');
  }

  function renderScores(): void {
    const list = el<HTMLOListElement>('score-list');
    list.innerHTML = '';
    if (scores.length === 0) {
      const li = document.createElement('li');
      li.textContent = 'No scores yet — set the first record!';
      list.appendChild(li);
      return;
    }
    for (const s of scores) {
      const li = document.createElement('li');
      li.textContent = `${s.initials}  ${String(s.score).padStart(6, '0')}  LV ${s.level}`;
      list.appendChild(li);
    }
  }

  function renderSettings(): void {
    for (const row of document.querySelectorAll<HTMLElement>('.setting-row')) {
      const key = row.dataset.setting as keyof Settings;
      const current = key === 'sound'
        ? (settings.sound ? 'on' : 'off')
        : String(settings[key]);
      for (const btn of row.querySelectorAll<HTMLButtonElement>('button')) {
        btn.classList.toggle('active', btn.dataset.value === current);
      }
    }
  }

  // settings rows: click a value → save + apply
  for (const row of document.querySelectorAll<HTMLElement>('.setting-row')) {
    row.addEventListener('click', (ev) => {
      const btn = (ev.target as HTMLElement).closest('button');
      if (!btn || !row.contains(btn)) return;
      const key = row.dataset.setting as keyof Settings;
      const val = btn.dataset.value ?? '';
      const next: Settings = { ...settings };
      if (key === 'sound') next.sound = val === 'on';
      else if (key === 'displaySize') next.displaySize = val as Settings['displaySize'];
      else if (key === 'playfield') next.playfield = val as Settings['playfield'];
      settings = next;
      saveSettings(settings);
      renderSettings();
      cb.onSettingsApplied(settings);
    });
  }

  el('btn-settings').addEventListener('click', () => {
    renderSettings();
    showOnly('settings');
  });
  el('btn-settings-back').addEventListener('click', () => showOnly('title'));
  el('btn-start').addEventListener('click', () => cb.onStart());
  overlays.pause.addEventListener('click', () => cb.onResume());

  el<HTMLButtonElement>('btn-gameover-ok').addEventListener('click', () => {
    pendingEntry = null;
    cb.onQuitToTitle();
  });

  el<HTMLFormElement>('initials-form').addEventListener('submit', (ev) => {
    ev.preventDefault();
    const input = el<HTMLInputElement>('initials-input');
    const initials = (input.value || 'AAA').toUpperCase()
      .replace(/[^A-Z0-9]/g, '').slice(0, 3).padEnd(3, 'A');
    if (pendingEntry) {
      scores = insertScore(scores, { ...pendingEntry, initials });
      saveScores(scores);
      pendingEntry = null;
      renderScores();
    }
    cb.onQuitToTitle();
  });

  function sync(g: Game): void {
    switch (g.state) {
      case 'title':
        renderScores();
        showOnly('title');
        break;
      case 'paused':
        showOnly('pause');
        break;
      case 'playing':
      case 'dying':
        showOnly(null);
        break;
      case 'levelclear':
        el('clear-summary').textContent =
          `Level ${g.level} cleared — ${Math.floor(g.pct * 100)}% filled!`;
        showOnly('levelclear');
        break;
      case 'gameover': {
        el('final-score').textContent =
          `SCORE ${String(g.score).padStart(6, '0')} — reached level ${g.level}`;
        const form = el<HTMLFormElement>('initials-form');
        if (pendingEntry === null && g.score > 0 && qualifiesForTopTen(scores, g.score)) {
          pendingEntry = {
            initials: '', score: g.score, level: g.level, date: new Date().toISOString(),
          };
          form.classList.remove('hidden');
          const input = el<HTMLInputElement>('initials-input');
          input.value = '';
          input.focus();
        } else if (pendingEntry === null) {
          form.classList.add('hidden');
        }
        showOnly('gameover');
        break;
      }
    }
  }

  renderScores();
  return { sync };
}
```

```ts
import './styles.css';
import { PRESETS } from './core/levels';
import {
  createGame, startGame, tick, togglePause, setDirection, drainEvents, returnToTitle,
  type Game,
} from './core/game';
import { Renderer } from './render/renderer';
import { attachInput } from './input/input';
import { GameAudio } from './audio/audio';
import { initScreens } from './ui/screens';
import { loadSettings, type Settings } from './persist/storage';

const canvas = document.getElementById('game') as HTMLCanvasElement;
let settings = loadSettings();
let game: Game = createGame(PRESETS[settings.playfield]);
let renderer = new Renderer(canvas, game.preset);
const audio = new GameAudio();
audio.setEnabled(settings.sound);

function applyDisplaySize(size: Settings['displaySize']): void {
  if (size === 'fullscreen') {
    if (!document.fullscreenElement && canvas.requestFullscreen) {
      canvas.requestFullscreen().catch(() => {});
    }
    return;
  }
  if (document.fullscreenElement) void document.exitFullscreen();
  const p = game.preset;
  const scale = size === 'fit'
    ? Math.min(window.innerWidth / p.canvasW, window.innerHeight / p.canvasH)
    : Number(size.charAt(0)); // '1x' → 1, '2x' → 2, '3x' → 3
  canvas.style.width = `${Math.floor(scale * p.canvasW)}px`;
  canvas.style.height = 'auto';
}

function applySettings(s: Settings): void {
  settings = s;
  audio.setEnabled(s.sound);
  const wanted = PRESETS[s.playfield];
  if (wanted.name !== game.preset.name) {
    game = createGame(wanted);          // settings are only reachable from the title,
    renderer = new Renderer(canvas, wanted); // so a preset switch restarts cleanly
    lastState = '';
  }
  applyDisplaySize(s.displaySize);
}

const handleStart = (): void => {
  audio.unlock();
  if (game.state === 'title' || game.state === 'gameover') startGame(game);
  else if (game.state === 'paused') togglePause(game);
};
const handlePause = (): void => {
  if (game.state === 'playing' || game.state === 'paused') togglePause(game);
  else if (game.state === 'gameover') returnToTitle(game);
};

attachInput({
  onDir: (d) => setDirection(game, d),
  onStart: handleStart,
  onPause: handlePause,
});

window.addEventListener('pointerdown', () => audio.unlock(), { once: true });
window.addEventListener('keydown', () => audio.unlock(), { once: true });

document.addEventListener('visibilitychange', () => {
  if (document.hidden && game.state === 'playing') togglePause(game);
});

const screens = initScreens({
  onStart: handleStart,
  onResume: () => {
    if (game.state === 'paused') togglePause(game);
  },
  onQuitToTitle: () => returnToTitle(game),
  onSettingsApplied: (s) => applySettings(s),
});

applyDisplaySize(settings.displaySize);
window.addEventListener('resize', () => {
  if (settings.displaySize === 'fit') applyDisplaySize('fit');
});

let lastState = '';
let last = performance.now();
let acc = 0;
function frame(now: number): void {
  acc += Math.min(now - last, 250);
  last = now;
  while (acc >= 1000 / 60) {
    tick(game);
    acc -= 1000 / 60;
  }
  for (const e of drainEvents(game)) {
    renderer.onEvent(e);
    audio.handle(e);
  }
  if (game.state !== lastState) {
    lastState = game.state;
    screens.sync(game);
  }
  renderer.draw(game);
  requestAnimationFrame(frame);
}

screens.sync(game); // paint the title screen immediately
lastState = game.state;
requestAnimationFrame(frame);
```

```js
// Generates public/icons/icon-{192,512}.png — black tile, magenta X, cyan frame.
// Raw RGBA → zlib deflate → PNG chunks with CRC32. No dependencies.
import { deflateSync } from 'node:zlib';
import { mkdirSync, writeFileSync } from 'node:fs';
import { dirname, join } from 'node:path';
import { fileURLToPath } from 'node:url';

const root = join(dirname(fileURLToPath(import.meta.url)), '..');
const outDir = join(root, 'public', 'icons');
mkdirSync(outDir, { recursive: true });

const CRC_TABLE = (() => {
  const t = new Uint32Array(256);
  for (let n = 0; n < 256; n++) {
    let c = n;
    for (let k = 0; k < 8; k++) c = c & 1 ? 0xedb88320 ^ (c >>> 1) : c >>> 1;
    t[n] = c >>> 0;
  }
  return t;
})();

function crc32(buf) {
  let c = 0xffffffff;
  for (let i = 0; i < buf.length; i++) c = CRC_TABLE[(c ^ buf[i]) & 0xff] ^ (c >>> 8);
  return (c ^ 0xffffffff) >>> 0;
}

function chunk(type, data) {
  const len = Buffer.alloc(4);
  len.writeUInt32BE(data.length, 0);
  const body = Buffer.concat([Buffer.from(type, 'ascii'), data]);
  const crc = Buffer.alloc(4);
  crc.writeUInt32BE(crc32(body), 0);
  return Buffer.concat([len, body, crc]);
}

function png(size) {
  const raw = Buffer.alloc(size * (1 + size * 4));
  const m = Math.floor(size * 0.18); // inner-box margin
  const t = Math.floor(size * 0.14); // X stroke half-thickness
  const f = Math.max(2, Math.floor(size * 0.03)); // frame thickness
  for (let y = 0; y < size; y++) {
    const row = y * (1 + size * 4);
    raw[row] = 0; // scanline filter: none
    for (let x = 0; x < size; x++) {
      const i = row + 1 + x * 4;
      let r = 0, g = 0, b = 0; // black background
      const inBox = x >= m && x < size - m && y >= m && y < size - m;
      const d1 = Math.abs(x - y) < t;
      const d2 = Math.abs(x - (size - 1 - y)) < t;
      if (inBox && (d1 || d2)) { r = 255; g = 0; b = 255; } // magenta X
      if (x < f || y < f || x >= size - f || y >= size - f) { r = 0; g = 255; b = 255; } // cyan frame
      raw[i] = r; raw[i + 1] = g; raw[i + 2] = b; raw[i + 3] = 255;
    }
  }
  const ihdr = Buffer.alloc(13);
  ihdr.writeUInt32BE(size, 0);
  ihdr.writeUInt32BE(size, 4);
  ihdr[8] = 8; // bit depth
  ihdr[9] = 6; // color type RGBA
  const sig = Buffer.from([0x89, 0x50, 0x4e, 0x47, 0x0d, 0x0a, 0x1a, 0x0a]);
  return Buffer.concat([
    sig,
    chunk('IHDR', ihdr),
    chunk('IDAT', deflateSync(raw, { level: 9 })),
    chunk('IEND', Buffer.alloc(0)),
  ]);
}

for (const size of [192, 512]) {
  const file = join(outDir, `icon-${size}.png`);
  writeFileSync(file, png(size));
  console.log(`wrote ${file}`);
}
```
